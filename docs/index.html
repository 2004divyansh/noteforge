Binary Search & Graph Traversal Notes
#ExamPrep #Algorithms

Binary search operates over a sorted array in O(log n) time complexity by repeatedly dividing the search interval in half.

// Binary search in O(log n) int binarySearch(List<int> arr, int target) { int low = 0, high = arr.length - 1; while (low <= high) { int mid = low + (high - low) ~/ 2; if (arr[mid] == target) return mid; if (arr[mid] < target) low = mid + 1; else high = mid - 1; } return -1; }
